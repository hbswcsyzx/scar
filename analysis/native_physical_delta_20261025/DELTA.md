# One joint recapture: native-only physical metadata delta

Current files cannot independently qualify C for an unheld native-only port. `tensor_physical.py:423–469` visits every TorchOp but emits TensorMetadata only for declared `scar-dispatch` held markers; it emits allocation events separately. The original native ETO tuple/shape/strides proves observed metadata, but its Tensor/storage IDs are not the event-tree tensor/allocation namespace. Matching dtype/shape, an allocation receipt, or a later held occurrence cannot supply the missing exact port→physical-epoch join. The old Run stays unchanged.

Extend the same joint source/environment/OS capture once, using the existing post-close event-tree traversal and `_tensor`/`_allocation` helpers, to retain every native TorchOp's ordered boxed TensorMetadata, including native-only ports. Keep original `scar` markers for the independent B held-object proof. This is an exporter field delta, not a new IR or a new target run per field.

Minimum retained data:

- Closed provider revision, capture/Run/process/nonce and original input-artifact receipts; complete traversal counters, truncation/frontier and error inventory.
- Each native TorchOp's name, event/result ID, exact provider RF/correlation field and RecordFunction thread token, parent event ID, traversal ordinal and timestamps. Preserve namespaces: Result ID is not RF/ETO node ID, DFS ordinal is not original ETO ordinal or provider Ev Idx, RecordFunction token is not Linux TID.
- For each actual input/output: direction, original boxed top-level ordinal and nested path, scalar/container/type shape, and original ETO node ID + original node ordinal + exact `inputs|outputs/values/<path>` locator. Join event-tree↔ETO only by the fixed provider's exact RF/thread contract and unique original event/node, checking parent/control relation, name/schema and ordered structure. Name, time proximity, dispatch sequence or shape alone does not establish the join.
- Each exposed TensorMetadata's `impl_ptr`, `storage_data_ptr`, provider tensor ID, provider allocation ID, device type/index/text, dtype, layout, sizes and strides; keep observed zero/missing/undefined distinctions, missing-field reasons and exact exporter source locator. `_tensor` currently has no storage offset: obtain it only from the exact joined ETO slot; never infer it from pointer differences.
- Original allocation/free/zero-size receipts, exact event header/locator, signed size, pointer, device, provider tensor/allocation IDs, totals and complete traversal status. Epoch is scoped by capture/Run/process/device/provider allocation ID. Check pointer and unique positive-birth extent; absent birth keeps extent/lifetime open.

Important implementation limit: current exporter reads `extra.inputs`; it does not demonstrate an installed native-output TensorMetadata API. Retain outputs only if the provider actually exposes them with exact original order, otherwise record an output-specific frontier. An output later observed as an input is another occurrence, not automatic proof at the earlier output. Do not invent an output field or insert Python output holders merely to fill the gap; any required provider binding delta belongs in the same reviewed capture preparation.
