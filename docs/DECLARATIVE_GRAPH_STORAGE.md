# 声明式图规范、归档与查询的职责

2026-10-25。**设计决定；不是新格式已实现或第一阶段已完成的声明。**
本文件落实用户关于声明式存储的要求。第一阶段范围仍由
[建模合同](FIRST_STAGE_MODEL_CONTRACT.md)规定。

## 1. 先定义图，再选择存储

SCAR 的规范应说明程序的实体、关系、身份、组合与合法性。JSON、数据库表和
文件布局都不能决定这些含义。声明式是指记录声明结构与事实，不要求读者执行
目标代码才能恢复图；它不意味着其中每个声明都已由真实证据证实。

保留已有的强类型模型和校验器，首先审计它们的实际声明及自动 producer。
不另造一套 Operation、producer、Use、state 或资源身份。不同表示之间通过
明确对应连接，不能按名称、裸 local ID、指针或文件位置合并。

## 2. 三层职责

| 层次 | 权威和职责 | 当前边界 |
| --- | --- | --- |
| 规范声明 | ProgramGraph 的静态操作/值/状态/区域/资源；ExecutionModel 的动态实例与对应；ValueGraph 的逻辑内容和物理表示；EvidenceGraph 的观测 | 各自使用已有 codec、版本和命名空间；关联不等于等价或完整性证明 |
| 归档编码 | 原声明和证据的精确编码、分片、receipt、版本、按需读取与发布 | 复用现有 inventory/source publication、bundle partitions 及不可变 artifact；尚没有完成整程序根产物的统一发布 |
| 查询索引 | 实体定位、typed 入出边、Region 展开及跨表示查询 | SQLite 是可删除、可重建的派生索引；当前只覆盖一份较旧源码快照，不能成为第二个可写事实来源 |

已有声明格式不等于已经有完整程序。当前缺口主要在自动产生和连接事实，
不应为了得到一个新的文件扩展名再迁移全部已验证记录。

## 3. 声明规范必须保留的内容

1. **类型与身份。** 区分定义、某次发生、对象、逻辑版本、storage/allocation、
   物理副本、资源实例与证据。ID 的作用域、代码/环境版本和跨文档引用必须明确。
2. **有序数据端口。** producer 与逐槽 Use 保持原记录；重复使用同一值不能
   去重成一条无序边。入口、返回、循环/分支参数及容器路径均须保留顺序。
3. **其它关系。** 状态读写及前后态、控制/异常、环境、包含、实际调用、
   alias/view、provenance、materialization、资源生命周期与异步顺序分别分型。
4. **递归与边界。** Region 的输入、结果、共享状态、资源、完成出口和内部展开
   独立声明。物理分片不是图边界；边界之外的依赖必须可引用和核对。
5. **来源与资格。** 静态推导、实际观测、版本化库合同和未满足条件分别记录；
   UNKNOWN 不能编码为 NONE，引用身份不能编码为内容相等，host 返回不能编码为 ready。
6. **版本与覆盖。** schema/capability、snapshot/parent、完整性分母、预算和未展开
   项不因分片、压缩或索引而消失。发布归档成功与模型完整通过分别记录。

这是现有模型的审查要求，不是在此新定义一套无校验的通用 node/edge metadata。
具体类、字段、codec 和 producer 的对应见 [实现审计](DECLARATIVE_MODEL_AUDIT.md)。

## 4. 保存、局部读取与并行

规范定义按真实 Region/body 和表示归档；动态记录按 Run、actor 和序列范围
分块。一个逻辑 Region 很大时可分成多个物理块，原 RegionID 与端口不变。
共享对象、状态和资源保留同一个准确身份，不为每片复制一份新的“相同”实体。

块的 stored/decoded receipt 与规范实体身份分开。hash 用于核对字节，不能直接
证明两个数据值相等或某次运行的数据未变化。跨片索引必须定位准确原命名空间、
record 和端口，不伪造原档中并不存在的 JSON pointer。

并行任务读取同一固定快照，按带接口的子图分工；输出声明原基础快照、所读依赖
和新增对应。发布者检查冲突及跨图关系后统一发布。文件数量不是并行正确性的
依据。第一阶段只恢复和连接模型，不发布优化变换。

## 5. 落实顺序和验收

先完成现有声明/实际 producer 的审计，再补缺失连接；只有发现现有格式不能
表达具体必需事实时才修订对应 schema。编码和查询可独立替换，但必须保持
准确身份、有序端口、原语义、证据范围和覆盖分母。

第一阶段最终统一入口与根产物应能自动定位全部参与快照和原证据，按需展开并
核对跨表示引用。是否需要一个新的顶层 manifest，由实际组合缺口决定，不能
先引入一个空壳 manifest 就称整程序已统一。优先复用已有 composition/capture。

SQLite 原实现保留为查询实验；不以建库、迁库或自写编码引擎作为建模完成的
前置。原索引实测与局限仍见 [GRAPH_INDEX.md](GRAPH_INDEX.md)。
