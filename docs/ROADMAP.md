# 开发路线

第一阶段：整程序纯静态建模与建图。当前实施顺序只维护在 [STATIC_ANALYSIS_PLAN](STATIC_ANALYSIS_PLAN.md)，不再维护多个并行 gate 队列。

完成标准是：对明确源码/依赖范围机械构造层次化图，连接数据、状态、控制及资源要求，尽可能推导确定或条件事实，并保留尚未展开和无法确定的具体原因。不能以节点数量、字段齐全或调用已有连线代替完成。

第二阶段：在完整模型上研究子图化简、等价关系及可修改区域，形成具体修改指导。

第三阶段：变换实施、必要的运行对应、正确性验证和成本决策。只有用户恢复该范围后才开展。

当前不进入第二、三阶段。实际状态见 [STATUS](STATUS.md)。
