## What is implemented

Typed context-domain/cleanup declarations and Enter/Resume/Replace/Read actions
connect to the existing canonical Uses, state SSA, lexical scopes and actual
CFG edges. Entry-relative copy/freshness and LIFO routing are derived queries;
they are not a second source of producers or arguments. Schema v9 tags the new
Route explicitly and preserves the old schemas and tagless C0 dispatch shape.
The v8 golden was produced with the original codec from an isolated
`588ca84` archive; its proof is in `tests/fixtures/`.

Generic hand-authored IR examples cover multiple state domains, Return/Raise,
nested cleanup, local Break/Continue, INVOKE normal/exceptional outcomes and
possible or complete divergence. Saved pending values, saved exception
context and current shared state remain separate dependencies.
