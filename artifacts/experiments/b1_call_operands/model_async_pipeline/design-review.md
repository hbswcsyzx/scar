## Entity and connection decisions

Keep Operation / Value / StateLocation / Region / Resource. Request R, body B,
latent request L and scheduler input S are original Value roles. A SessionUpdate
is an attachment to one original operation and its existing state ports; a
BodyDriveExecution links an actual Drive to one persistent activation/segment.
No new phase/state/epoch graph or canonical record is needed for this gate.

Static analysis must inventory obligations from original Drive/outcome edges,
not from supplied consumer declarations. A missing declaration cannot erase its
source. One selected path correlates R/B/current state together; may-reach and
independent successful endpoints are insufficient for a joint tuple.

Dynamic analysis uses actual ControlTransfer/BlockVisit/segment and original
operation ports. Same static site, same type or a sole captured candidate never
selects another occurrence. Reuse existing CFG/CALL/body predecessor recipes and
fresh scoped identity compatibility; seed new session/host endpoints into that
same necessary ancestor closure. No tensor content or second SSA is recorded.

Three distinct driver activations can act on one R and one B. B has one
persistent activation with three segments; ResumeIngress names its exact old
Suspend occurrence/edge. R COMPLETE does not terminate or free B. An item
adapter can correctly end with host RAISE StopIteration(item); a synthetic
NORMAL branch would change the modeled program.

## Root execution projection review

A read-only independent source audit found three concrete risks before the
first execution integration run. These are source findings, not independently
reproduced runtime bugs:

1. Physical slot zero is not a generic exception packet port. Resolve the
   original RAISE signature's EXCEPTION_PACKET slot through its exact selected
   CompletionResult/landing formal; host payload Uses are non-state Uses.
2. State maps alone do not show captured state operands. Preserve original
   state UseOccurrence/value/current receipts and lifecycle input/output domain
   support; missing capture makes the local session partial and withholds post.
3. Scope is part of an AsyncSessionOutcome key. Preserve every exact scope's
   binding obligation; one scope's declaration cannot discharge another's.

Root incorporated all three, plus driver entry-R to actual Drive.session Use
compatibility. The existing shared query budget precedes session checks;
unchecked rows retain source/target counts and mask compatibility/post claims.
Existing fresh external-context hooks recompute compatibility; public query
detaches once. Native/source/runtime/transform flags remain false.
