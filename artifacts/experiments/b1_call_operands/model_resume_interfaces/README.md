# C2 resumption architecture review evidence

2026-10-17; baseline `fec9f5b426caad5e0c974c9bd99c42a0fb256882`.
**Design evidence only. C2.0 exact-field freeze is OPEN; C2 is not implemented.**
The authoritative proposal is `docs/M1_RESUMPTION_INTERFACES.md`.

## Evidence classes

| Class | Actual scope |
| --- | --- |
| Observed | CPython 3.14.7 stdlib probes: 23 initial dynamic observation groups, four bytecode code shapes, then four separate delegation-context groups. Observation counts are not assertion-test counts. |
| Verified | Five design-only availability checks on existing validator-valid synchronous core fixtures match their expected unavailable Uses. No Suspend record is supplied or validated. |
| Inferred | Existing core/FrameExit invariants cannot simply be reused for suspension; source-level CPython context/delegation paths constrain the proposed interface. |
| Proposed | One logical body with temporal successors; cut availability; private saved values/current shared-state ingress; phase-specific context and driver/body relations. |
| Implemented | No C2 product capability, wire change, lowerer, collector or backend. The existing C1 implementation remains unchanged. |
| Rejected | Suspend-as-Return; flat saved exception/None; old world restored on resume; accepted request always entering parent body; silently reusing synchronous FrameExit adjacency. These are rejected designs, not measured backend decisions. |

## Files and chronology

- `review/control-design.md`, `composition-review.md` and
  `language-provider-review.md` are independent initial reports. Their earlier
  caller-token/phase alternatives remain historical proposals, not final fields.
- `review/language-{runtime,delegation,exception-context,bytecode}-probe.py/.json`
  are the original bounded stdlib witnesses. They do not import SCAR or torch,
  hold application frames, capture LeWM or install dependencies.
- `review/language-delegate-context-probe.py/.json` and its follow-up report
  retain four later observations: parent next/send context differs from the
  delegate callbacks directly dispatched by parent throw/close.
- `review/availability-probe.py/.json` projects hypothetical extra roots onto
  the existing core loop fixture; no new mutable graph representation or
  implemented suspension semantics is claimed.
- `review/final-design-review.md` reviews the first 166-line main proposal and
  keeps six exact-field obligations open. Root then clarified that ingress
  state includes delegate effects, rather than the earliest gate's old state.
- `review/root-resolution.md` states the final architecture decisions and
  remaining implementation obligations without rewriting the original reports.

The source fingerprint is unchanged from C1. Its 3,330-test result belongs to
that earlier frozen implementation, not to these unimplemented interfaces.
No new full run, workload profiling, automatic LeWM graph or speedup is claimed.
The complete first modeling stage remains unfinished.

`manifest.json` binds this owned evidence. `check_review.py` checks hashes and
the stored witness scopes/counts without rerunning probes, pytest or workloads.
`review_checks.json` additionally records the current product fingerprint and
the local links checked at archival time. Generated bytecode and caches are
excluded; no third-party sources, Tensor payloads or runtime frames are archived.
