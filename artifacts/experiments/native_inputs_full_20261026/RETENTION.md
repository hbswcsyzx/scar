# Retention

Git retains only the five feature sources, API notes, reviewed diffs, exact source snapshots, terminal/failure reports, runners and complete small manifest receipts. Original capture and formal native program/execution/value/evidence/projection outputs remain at their exact local URIs; no implicit relocation is claimed. Hardware raw identifiers and original bulk traces are not copied to Git.

OUTPUT_SIZES.json is stat-only; manifest receipts reuse writer SHA/bytes and do not rehash/reparse multi-GB outputs. Metadata rows: 1,149,058,252 raw /47,315,004 gzip bytes; associations:274,582,619 raw /14,867,882 gzip bytes. Principal repetition in canonical outputs is grouped by original filename in that receipt; no new compression format was introduced.

Private navigation indices are disposable authenticated session state, not graph authority. Root owns cleanup of terminal attempts01–04; attempt05 cleanup follows successful ordinary published-result querying/navigation. Size/deletion receipts will be retained separately. Source program publication/catalog/core and four protected dirty files are excluded.
