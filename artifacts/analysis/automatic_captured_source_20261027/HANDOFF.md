# Entry points

`scar.analysis.model_run.run_model(capture, out, *, plan_only=False, resume=False, budget=ModelRunBudget(), source_only=False)` keeps the default full route. The optional `source_only=True` uses the identical normal source helper without native import/binding. No manual source-owner option is required.

`read_call_source_seeds(..., coordinates=None)` auto-detects a closed PROGRAM_PORTS process; model-run supplies normal coordinates for exact membership. Its private live source session is passed to the normal inventory workspace and `reconstruct_source_layers(..., captured_source_session=...)`. Seed wire remains unchanged; serialized report decoding creates a fresh normal scan/owner rather than restoring a live session. Captured source admission precedes every workload `CodeWitnessStore.resolve`; readonly descriptor verification remains independent.

`CURRENT_STATIC_NAMESPACE_INPUT` describes the current root initializer naming policy only. Multi-process captures without one exact declared source membership are explicitly rejected by the current single-owner adapter, not resolved by a filename guess. No SourceEntryCatalog, SourceAttachments or second inventory is minted.
