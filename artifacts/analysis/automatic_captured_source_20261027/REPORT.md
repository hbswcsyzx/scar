# Automatic captured source bootstrap

Implemented on `b28e129e` in six analysis files. `run_model` automatically selects the exact coordinate-declared captured-source metadata, builds its normal owner from the same normal frame scan, and passes that live session through seeds, workspace, discovery, inventory, source layers and workload CodeWitness. The default full route calls this same source-stage implementation. No caller-owned JSON report, bare text, or success Boolean constructs the owner. Original seed/inventory/layer/composition and core graph schemas are unchanged.

The package naming policy is normal discovery's current static initializer policy, recorded as `CURRENT_STATIC_NAMESPACE_INPUT`; it is not evidence of a loaded module or import. Captured filenames use retained bytes and an unavailable archive remains a frontier. Additional uncaptured static files retain their old discovery path and are separately recorded as `CURRENT_STATIC_UNEXECUTED_SOURCE_VERSION`, without same-capture qualification. Namespace changes during this construction are rejected.
