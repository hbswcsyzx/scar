The compact V2/V3 reader authenticates the complete original root receipt/plan SHA/denominator and common parent fields, then groups using catalog.metadata().candidates.file_key without resolving any source for sorting. For each group it invokes the existing ordinary planner, compares common fields and every expectation against that group's original root indices, then immediately runs the original body-check loop. Existing per-body loop is textually unchanged. checked[index] preserves original manifest order. Global duplicate entry/qualified-definition checks remain. Noncompact still uses its original full plan/SourceProgram path. V1 compact sorting also uses metadata.

Old timer: SourceFragmentWriter is created at the first shared body and seconds1800 bounds the entire writer batch; each SourceContextSession separately starts its own1800 clock per file. Thus a large correctly progressing whole-model body batch can hit an unintended writer deadline.

New explicit CompositionIndex.from_source_entry_publication(..., max_context_seconds=1800) forwards through the compact public reader/private session. For this explicit reader mode, finish_group closes/deep-checks the actual context and finishes the file's writer before the next group's planning; the next writer gets a fresh per-file clock. Whole-batch byte counters and all original input stamps remain the same private shared objects, so no cumulative byte or final input-stability guard is reset. No cached legality bool/token is introduced. Legacy shared publisher sessions use None and retain their old whole-writer1800 semantics. Full noncompact readers do not enable the new policy. Existing already-active private reader sessions retain their caller-owned policy.

max_context_seconds is the source-file context IO/body validation ceiling, including its normal close checks. It is not a global model deadline and excludes earlier composition/catalog construction and per-group planner setup. Callers retain their outer wall deadline. No blind larger fixed wall number is introduced, and this patch does not fix the separately observed long pre-publication composition-construction stage.
