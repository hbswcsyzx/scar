# Collection scope: main model versus supporting evidence

This is a read-only design audit after the single fixed-scope capture, not a smaller completeness denominator or permission to remove existing dependencies. Actual capture results and exact source receipts are in `artifacts/experiments/lewm_joint_capture_fixed_scope_20261026/{REPORT.md,SOURCE_RECEIPTS.json,STOP_DIAGNOSTIC.json}`. No collector changes or further capture are made here.

The program model should expose adjustable source/native/resource actions, CFG/def-use, effect/state ports, code/entry identity and conservative interfaces for unexpanded regions. An instruction callback, collector registration, syscall-log line or process-map snapshot is supporting evidence; it does not automatically become a separate program action. Unexpanded internals retain expansion/effect debt and cannot become complete merely because their boundary is represented.

The minimally sufficient direction is static structure first, then exact dispatch/region entry+exit and only required input/output/state/alias/storage/completion ports. Unknown bodies retain typed region interfaces and full conservative effects; this is coverage modeling with debt, not optimization authorization. CodeVersion/SourceSnapshot, Run/process and artifact namespaces remain distinct. Necessary resource readiness/lifetime or content proof must not be deleted because an internal implementation is unexpanded.

Failure isolation must also be explicit: an unsupported call/port or one activation's missing-entry proof should invalidate that activation/region and dependent conclusions, preserving other independent source/static and dynamic evidence. A shared hook/tool/source-integrity failure can invalidate the wider hook epoch/run. The current terminal `INSTRUCTION_FRAME_UNAVAILABLE` sets a global operand stop, while its GAP omits CodeID/offset; the next contract should retain the actual available code/site and scoped frontier, without inventing an invocation or returning monitoring DISABLE for later valid offsets. Budget saturation needs explicit scoped debt plus a flushed health/stop receipt, not a successful CLI exit interpreted as coverage.

No budget increase or new LeWM episode is proposed. First specify the exact static bodies/ports and their invalidation rules, preserve old profiles/artifacts, and reuse the retained partial evidence only within its demonstrated scope. The current raw trace costs and gaps are reasons to contract the observation interface, not reasons to claim fewer program dependencies exist.
