# Program-interface OS observation and parallel byte archival

The owned launcher now supports explicit `all` and `program-interfaces` selection contracts. CLI defaults to program-interfaces; the Python launcher API preserves its former all default. The finite program-interface scope retains process/handle identity controls, file and range IO, mappings, device commands, endpoint IO and explicit wait interfaces. Unlisted kernel/scheduler internals are excluded. The original actual-argv/control-name validator remains in force. Intent, actual launch and coverage must agree on the exact new selection contract; neither unknown scope nor zero event count grants absence inference.

For selected interfaces the launcher requests `--seccomp-bpf`. The installed strace6.8 manual says selection alone may still stop every syscall, and seccomp setup can fall back. Therefore metadata says REQUESTED_NOT_VERIFIED. An owned /bin/true provider run exited0 with empty diagnostics, the exact selection/identity-control reader accepted it, and a changed scope was rejected. Its already-closed bytes also passed the ordinary archive path; no second target was launched. This is provider/transport verification, not complete Python/native graph verification or a speedup measurement.

The same compression helper ran with4 threads on the stopped real LeWM capture:8,027,996,678 raw bytes →677,057,591 stored bytes in38.746s. Every member was decompressed and SHA/length checked before a partial archive manifest was published and duplicate originals removed. Total stored-byte accounting is locked across workers; source stamps are checked before cleanup. The partial schema/path is distinct from a successful capture archive and preserves the original timeout/exit241. Closed collector metadata and original failed-run receipts remain in place. See that run's ARCHIVAL_RESULT.json and capture/partial-archive-index.json. No LeWM data or shared cache was removed.

The launcher also bounds aggregate owned trace bytes/member count while running, so Python/Torch sidecars cannot escape the OS-only byte check and fail solely at late archival. This monitor change has syntax review, pending the next actual LeWM run. The newly exposed active-weak-reference ceiling is a metadata budget, not a Tensor-content cache.

The public dependency batch command also read the existing two-call model and emitted7 untruncated views (current_dependency_cli.json.gz). New shard-builder/process-worker commands were wired and their parser entries checked; their APIs have separate actual512-candidate/4-process receipts. No extra full raw replay was done for CLI wiring.
