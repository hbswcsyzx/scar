The frame recorder now has a private first-reason **entry-admission stop**, separate from closed/_closing. Event/code/byte/transport rejection stops new entries before the process-ports fallback ancestor walk. It still counts skipped observations as dropped, attempts returns for previously retained frames, and keeps the previous profile callback. Event admission reserves one event slot per outstanding return; IO/byte failure can still prevent a return and remains an explicit incomplete frontier. Operand quota/transport failures propagate the admission stop, later CALL callbacks stop before expensive processing, and retained frame returns can still release their original owned masks/state. No shutdown phase marker is emitted by quota handling.

On failed materialization, operand close records `OPERAND_MATERIALIZATION_UNAVAILABLE` alongside the original OSError and sets io_failed. It does not dereference absent DeferredJsonl.result or invent an operand SHA/legacy handoff. Stream metadata is marked stopped with `OPERAND_INPUT_HANDOFF_UNAVAILABLE` and no verified inputs. Nested finally cleanup closes stream, environment and target siblings and detaches the observer even if one close raises; process-control exceptions are not swallowed. Successful materialization keeps the original ordinary handoff.
